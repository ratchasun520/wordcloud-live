# Word Cloud Psycho-CU

ระบบ Word Cloud แบบสดสำหรับห้องอบรมหรือห้องประชุม ผู้ดูแลตั้งคำถาม ผู้เล่นสแกน QR แล้วตอบจากโทรศัพท์ คำตอบที่เหมือนกันหรือมีความหมายใกล้กันจะรวมเป็นกลุ่มเดียวและขยายใหญ่ขึ้นบนจอหลักทันที

ชุดคำถามตั้งต้นเป็นเรื่อง **แนวคิดการพัฒนาระบบสุขภาพที่ยั่งยืน** แก้ไข เพิ่ม หรือลบได้จากหน้าผู้ดูแล

## ความสามารถ

**ผู้ดูแล** (`/admin`)
- เข้าสู่ระบบด้วยรหัสผ่านที่ตั้งไว้ใน Netlify
- สร้าง แก้ไข ลบ และจัดลำดับคำถาม
- เลือกแบบคำถามได้ 3 แบบ
  - **Word Cloud**: ตอบเป็นคำสั้นๆ ได้ 1–5 คำต่อคน
  - **ตัวเลือก**: เลือกหนึ่งข้อจาก 2–8 ตัวเลือก
  - **คำตอบยาว**: ตอบเป็นประโยค แล้ว AI สรุปเป็นประเด็นสั้นๆ
- ตั้งเวลาตอบแต่ละข้อได้ (10–600 วินาที) และกด +15 วินาทีหรือปิดรับคำตอบก่อนเวลาได้
- QR code และลิงก์สำหรับให้ผู้เล่นเข้าร่วม
- เกมเริ่มเมื่อกด “เริ่มเกม” เท่านั้น ก่อนเริ่มจะมีนับถอยหลัง 3 วินาที
- จอหลักแสดงเมฆคำ คำที่มีคนตอบมากจะใหญ่ขึ้นเรื่อยๆ และมีตารางคำตอบของผู้เล่นทุกคน (เวลา ชื่อ คำตอบ กลุ่มคำ) อยู่ด้านล่าง
- AI จัดกลุ่มคำที่ความหมายเหมือนกัน เช่น คำพ้องความหมาย คำสะกดผิด คำย่อ หรือคำไทยกับอังกฤษที่มีความหมายเดียวกัน
- เพลงบรรเลงเบาๆ ระหว่างเปิดรับคำตอบ สร้างจากเบราว์เซอร์โดยตรง จึงไม่มีไฟล์เพลงหรือปัญหาลิขสิทธิ์
- โหมดเต็มจอสำหรับโปรเจกเตอร์

**ผู้เล่น** (`/play`)
- สแกน QR แล้วใส่ชื่อเพื่อเข้าร่วม ไม่ต้องสมัครสมาชิก
- เห็นเฉพาะหน้าจอคำถามของตัวเอง มองไม่เห็นคำตอบของคนอื่น
- คำถามขึ้นอัตโนมัติเมื่อผู้ดูแลกดเริ่ม ไม่ต้องรีเฟรช
- เปิด/ปิดเพลงบนโทรศัพท์ได้เอง (ปิดไว้เป็นค่าเริ่มต้น เพื่อไม่ให้โทรศัพท์หลายเครื่องดังพร้อมกัน)

## Deploy ขึ้น Netlify

1. เข้า [app.netlify.com](https://app.netlify.com) แล้วเลือก **Add new site → Import an existing project → GitHub** จากนั้นเลือก repo นี้
2. ไม่ต้องตั้ง Build command เพราะค่าทั้งหมดอยู่ใน `netlify.toml` แล้ว (เผยแพร่โฟลเดอร์ `public` และใช้ฟังก์ชันใน `netlify/functions`)
3. ไปที่ **Site configuration → Environment variables** แล้วเพิ่มค่าต่อไปนี้

   | ชื่อ | จำเป็น | คำอธิบาย |
   |---|---|---|
   | `ADMIN_PASSWORD` | ต้องมี | รหัสผ่านเข้าหน้าผู้ดูแล ควรยาวอย่างน้อย 10 ตัวอักษร |
   | `ANTHROPIC_API_KEY` | ไม่บังคับ | คีย์ Claude API สำหรับให้ AI จัดกลุ่มคำ สร้างได้ที่ [console.anthropic.com](https://console.anthropic.com) คิดค่าใช้จ่ายตามการใช้งานจริงในบัญชีของคุณ |
   | `ANTHROPIC_MODEL` | ไม่บังคับ | ชื่อโมเดลที่ใช้จัดกลุ่ม ค่าเริ่มต้นคือ `claude-haiku-5-5` ซึ่งเร็วและประหยัด |

4. กด **Deploy** (หรือ **Trigger deploy** ถ้าเพิ่มตัวแปรหลังจาก deploy ครั้งแรก เพราะตัวแปรจะมีผลกับการ deploy ครั้งถัดไป)
5. เปิด `https://<ชื่อเว็บของคุณ>.netlify.app/admin` แล้วเข้าสู่ระบบ

ข้อมูลเกม (คำถาม ผู้เล่น คำตอบ) เก็บใน Netlify Blobs ของเว็บไซต์นั้นโดยอัตโนมัติ ไม่ต้องตั้งฐานข้อมูลเพิ่ม

ถ้าไม่ได้ใส่ `ANTHROPIC_API_KEY` ระบบยังทำงานได้ แต่จะรวมเฉพาะคำที่สะกดเหมือนหรือคล้ายกัน เช่น “ความยั่งยืน” กับ “ความยั่งยืนน” แต่จะไม่รวมคำที่สะกดต่างกันแต่ความหมายเหมือนกัน เช่น “หมอ” กับ “แพทย์”

## วิธีใช้ในวันจริง

1. ก่อนเริ่ม เปิด `/admin` บนคอมพิวเตอร์ที่ต่อโปรเจกเตอร์ แล้วตรวจชุดคำถามในแท็บ **คำถาม**
2. กด **ล้างผู้เล่นและคำตอบทั้งหมด** ถ้าเคยทดลองเล่นมาก่อน
3. ให้ผู้เล่นสแกน QR บนจอ ชื่อของแต่ละคนจะขึ้นบนจอเมื่อเข้าร่วม
4. คลิกที่หน้าเว็บหนึ่งครั้งเพื่อให้เบราว์เซอร์อนุญาตเสียงเพลง แล้วกด **เริ่มเกม**
5. ระหว่างแต่ละข้อใช้ปุ่ม **+15 วินาที**, **ปิดรับคำตอบ**, **ข้อถัดไป** และ **แสดง QR** (สำหรับคนที่มาสาย)
6. กด **เต็มจอ** เพื่อซ่อนปุ่มควบคุมระหว่างนำเสนอ และกด Esc เพื่อออก

## ทดลองบนเครื่องตัวเอง

ต้องมี Node.js 18 ขึ้นไป

```bash
ADMIN_PASSWORD=1234 npm run dev
```

แล้วเปิด http://localhost:8888/admin (ข้อมูลอยู่ในหน่วยความจำและหายเมื่อปิดโปรแกรม) ถ้าต้องการทดสอบ AI ให้เพิ่ม `ANTHROPIC_API_KEY=...` หน้าคำสั่ง

รันชุดทดสอบด้วย `npm test`

## โครงสร้างไฟล์

```
public/                 หน้าเว็บ
  admin.html            หน้าผู้ดูแลและจอหลัก
  play.html             หน้าผู้เล่น
  js/cloud.js           การจัดวางเมฆคำ
  js/music.js           เพลงบรรเลงเบาๆ (Web Audio)
  js/qr.js              ตัวสร้าง QR code
netlify/functions/api.mjs   API บน Netlify Functions
netlify/lib/core.mjs        ตรรกะเกม การตรวจสิทธิ์ และการจัดกลุ่มด้วย AI
scripts/dev-server.mjs      เซิร์ฟเวอร์สำหรับทดลองบนเครื่อง
tests/                      ชุดทดสอบ
```

## หมายเหตุ

- หน้าเว็บอัปเดตด้วยการถามเซิร์ฟเวอร์ทุก 1.5–2 วินาที ผู้เล่น 30 คนเล่นหนึ่งชั่วโมงจะเรียกใช้ Netlify Functions ประมาณ 60,000 ครั้ง ควรตรวจโควตาของแผน Netlify ที่ใช้อยู่ในหน้า Usage
- คีย์ AI อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ผู้เล่นมองไม่เห็น
- ผู้เล่นส่งคำตอบได้ข้อละหนึ่งครั้ง และส่งได้เฉพาะช่วงที่ข้อนั้นเปิดรับคำตอบ
